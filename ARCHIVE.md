## Что означает «заморожен»

Разрешено:

- читать, копировать, форкать, изучать;
- исправлять опечатки в документации;
- запускать локально для обучения;
- ссылаться на проект как на пример.

Не предполагается:

- добавлять возможности, поставщиков, эндпоинты;
- менять контракт API;
- обновлять зависимости «до актуальных»;
- доводить известные дефекты ниже — они часть учебного материала.

Если вы всё же меняете код, считайте это новым проектом и снимите тег заморозки.

## Что проверено при консервации

Документация писалась не по памяти: утверждения сверены с кодом и с живым сервисом.

| Проверка | Команда | Результат |
|---|---|---|
| Окружение | `python -c "import fastapi, openai, anthropic, httpx2, pydantic"` | Python 3.12.12, все модули на месте |
| Старт сервиса | `uvicorn main:app --port 8001` | приложение стартует, `/health` → `{"status":"ok"}` |
| Реестр моделей | `GET /models` | 4 записи; `text_generation` = `supported`, остальные три = `unknown` |
| Прямой вызов | `POST /generate?provider=openai` | `200`, `finish_reason: max_output_tokens` при лимите 20 |
| Маршрутизация | `POST /generate/auto` | `200`, `route_version: routing-v1`, один `attempt` (`openai`, `completed`) |
| Ошибка контракта | `POST /generate?provider=ollama` с чужой моделью | `400`, `{"message": "...", "retryable": false}` |
| Ошибка схемы | `POST /generate?provider=gemini` | `422`, `literal_error` от FastAPI |
| Пустой запрос | `POST /generate/auto` с `messages: []` | `422`, `too_short` |
| Документация API | `GET /docs`, `GET /openapi.json` | `200`; пути `/health`, `/models`, `/generate`, `/generate/auto` |
| Цифры в документации | пересчёт из `artifacts/*.json` | значения в [docs/08](docs/08-evaluation.md) совпадают с артефактами |

Замечание про окружение: сервис на момент проверки уже слушал `127.0.0.1:8001` (запущен ранее),
поэтому проверки выполнялись на нём; повторный запуск на том же порту ожидаемо падает с
`WinError 10048`.

## Известные дефекты, оставленные сознательно

1. **`httpx2` отсутствует в [pyproject.toml](pyproject.toml).** Код импортирует его напрямую
   ([app/providers/ollama_provider.py](app/providers/ollama_provider.py#L3)), но зависимость
   приходит транзитивно от `anthropic`. Свежая установка работает, честность манифеста — нет.
2. **Конфигурация читается при импорте.** [app/api/routes/generation.py](app/api/routes/generation.py#L33-L85)
   создаёт четырёх провайдеров и читает `.env` в момент импорта; там же читается политика.
   Следствия: обязательны неиспользуемые переменные, тесты требуют полного окружения.
3. **Нет аутентификации клиентов и ограничения частоты.** Шлюз рассчитан на `127.0.0.1`.
4. **`401` поставщика отдаётся как `502`.** Спорное отображение, разобрано в
   [docs/07-errors.md](docs/07-errors.md#что-можно-критиковать-в-этой-схеме).
5. **При полном отказе маршрута журнал попыток теряется** — клиент видит только последнюю ошибку.
6. **Нет автотестов.** Проверка выполнялась смоук-запросами.
7. **Флаги `RoutingState` не выставляются** — `output_started` и `external_action_completed`
   всегда `False`, потому что потоковой выдачи нет. Сам объект участвует в решении о резерве
   ([app/gateway/routing.py](app/gateway/routing.py#L84-L91)); это записанный инвариант на будущее.
8. **`CapabilityState.LIMITED` объявлен, но не применяется нигде.**

## Как воспроизвести

```bash
uv sync
cp .env.example .env      # заполнить ключи и адреса
uv run uvicorn main:app --port 8001

curl http://127.0.0.1:8001/health
curl http://127.0.0.1:8001/models
```

Оценка моделей (платные вызовы, требует ключей):

```bash
uv run python -m scripts.evaluate_models
```

Сравнение квантизаций (требует локальной Ollama и двух скачанных моделей):

```bash
ollama pull qwen3:0.6b-q4_K_M
ollama pull qwen3:0.6b-fp16
uv run python -m scripts.compare_local_quantizations
```

## Как продолжить

1. Форкните репозиторий в новый проект, снимите тег и обновите статус в этом файле.
2. Начните с [docs/10-exercises.md](docs/10-exercises.md): первые три задания закрывают главные
   дефекты (ленивая конфигурация, журнал попыток, коды ошибок).
3. Перед добавлением поставщика прочитайте [docs/02-architecture.md](docs/02-architecture.md#точки-расширения) —
   там три шага и ни одного изменения в ядре.
